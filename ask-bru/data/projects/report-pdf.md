# Report PDF — prueba técnica para Footprint Mappa

## Qué es

Una app que convierte un CSV en un informe PDF de huella de carbono (OCF) con estadísticas y gráficos. Fue la prueba de acceso para la empresa Footprint Mappa.

## Stack

Next.js 16, React 19, Tailwind CSS, Xano, Vercel.

## Qué hizo Bru

Fue más allá del encargo y añadió scraping de la web del cliente para personalizar el informe con sus propios datos. Implementó autenticación contra una base de datos en Xano, un chat de IA que explica el reporte y un agente de IA (también sobre Xano) que genera recomendaciones para reducir la huella de carbono.

## Cómo

Construyó frontend y API completos en una semana, con herramientas que no conocía, apoyándose en IA para programar (vibe coding).

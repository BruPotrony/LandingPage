## Proyectos

### App de planta sobre Odoo — Masterfoam
- Stack: Python, Odoo (ORM/APIs), Vue.js, JavaScript.
- Proceso anterior: el operario de máquina anotaba a mano los registros (controles de calidad, cantidad producida, cantidad desechada). Después, otra persona pasaba esos datos en papel al sistema Odoo. Por último, una tercera persona hacía revisiones semanales para comprobar que todo estuviera correcto.
- Proceso actual: el operario introduce los datos directamente en una tablet junto a la máquina, de forma sencilla. Solo queda la revisión semanal.
- Qué es: app de planta sobre Odoo para automatizar producción, materiales, stock, ubicaciones y fichajes, pensada para usarse desde una tablet en cada puesto de trabajo de la fábrica.
- Qué hizo Bru: desarrollo en solitario, de principio a fin. Frontend en Vue y módulos y funciones personalizadas en Python conectados a Odoo (ORM, controladores/APIs). Cubrió análisis, desarrollo, despliegue y formación a toda la empresa, siguiendo buenas prácticas y tests bajo supervisión de código externa.
- Resultado: más de 20 operarios la usan a diario y uno de los procesos pasó de necesitar 3 personas a 1.
- Código: privado (propiedad de la empresa).

### Ask Bru — el chat de este portfolio (en desarrollo)
- Stack: Python, FastAPI, Supabase (Postgres + pgvector), Gemini con Groq como fallback, MCP, Langfuse, Render, GitHub Actions.
- Qué es: un agente integrado en brupotrony.com que responde preguntas sobre Bru, citando las fuentes.
- Cómo funciona: RAG con búsqueda híbrida (vectorial + full-text, combinadas con RRF) sobre su CV, las descripciones de sus proyectos y los READMEs de GitHub, que se sincronizan automáticamente cada día. El agente usa tools (buscar en la base de conocimiento, consultar repos de GitHub, buscar proyectos por tecnología, obtener contacto y CV) con un loop propio sin LangChain. Las mismas tools se exponen como servidor MCP.
- Calidad y producción: evals de retrieval y del agente, observabilidad con Langfuse, streaming, rate limiting, guardrails frente a prompt injection, tests con pytest y CI/CD por niveles.
- Estado: se está construyendo por fases (primero RAG y chat, después tools, después MCP y evals).

### Report PDF — prueba técnica para Footprint Mappa
- Stack: Next.js 16, React 19, Tailwind CSS, Xano, Vercel.
- Qué es: una app que convierte un CSV en un informe PDF de huella de carbono (OCF) con estadísticas y gráficos. Fue la prueba de acceso para la empresa Footprint Mappa.
- Qué hizo Bru: fue más allá del encargo y añadió scraping de la web del cliente para personalizar el informe con sus propios datos. Implementó autenticación contra una base de datos en Xano, un chat de IA que explica el reporte y un agente de IA (también sobre Xano) que genera recomendaciones para reducir la huella de carbono.
- Cómo: construyó frontend y API completos en una semana, con herramientas que no conocía, apoyándose en IA para programar (vibe coding).
- GitHub: https://github.com/BruPotrony/report_builder
- Demo: https://report-builder-lemon.vercel.app

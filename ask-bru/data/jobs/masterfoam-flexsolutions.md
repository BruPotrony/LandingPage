# Masterfoam Flexsolutions

## Sobre la empresa

Masterfoam Flexsolutions S.L.U., empresa con planta de producción en Òdena (Igualada). Tras las prácticas, Bru fue contratado 6 meses como desarrollador.

## Desarrollador Python / JavaScript para Odoo (enero 2026 – junio 2026)

- Automatizó procesos de planta (stock, producción y control de fichajes) desarrollando funcionalidades backend y APIs REST sobre Odoo, reduciendo la intervención manual de un proceso de 3 operarios a 1.
- Desarrolló el frontend en Vue.js conectado a Odoo vía API REST, usado a diario por más de 20 trabajadores en planta desde tablets en cada puesto de trabajo.
- Se encargó de los despliegues y asumió la responsabilidad técnica del proyecto de principio a fin.
- Formó a más de 20 usuarios y recogió requisitos directamente de los operarios para ajustar la aplicación al flujo real de trabajo.

## Prácticas de desarrollo de software (octubre 2025 – enero 2026)

- Desarrolló módulos personalizados en Odoo con Python y XML: modelos, vistas, lógica de negocio, tests y documentación técnica.

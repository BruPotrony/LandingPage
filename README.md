# LandingPage

Landing page personal de Bru Potrony Lopez.

## Estructura

- index.html
- style.css
- script.js
- assets/profile.jpg

## Uso

1. Instala Node.js (incluye npm).
2. Instala dependencias:

	npm install

3. Ejecuta en local:

	npm run dev

4. Compila para produccion:

	npm run build

El resultado de build se genera en la carpeta `dist/`.

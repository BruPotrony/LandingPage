# Risk Multiplayer — trabajo final del CFGS DAM

## Qué es

Adaptación multijugador del juego Risk, desarrollada en equipo de 3 personas.

## Stack

C#, .NET, WPF, Java 21, Spring Boot, MySQL, WebSockets.

## Qué hizo Bru

Fue responsable del cliente de escritorio en WPF (C# / .NET), con la interfaz y la lógica de juego, conectado por WebSockets a un backend en Java 21 y Spring Boot sobre MySQL. Arquitectura cliente-servidor con varios jugadores conectados en tiempo real.

## Qué aprendió

Contenedores, servidores, bases de datos y comunicación en tiempo real con WebSockets.
